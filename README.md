# CocoApp Solutions - Website

Sitio web corporativo para **CocoApp Solutions**, expertos en consultoría tecnológica, Microsoft 365, Power Platform, Inteligencia Artificial y Ciberseguridad en Chile.

## 🚀 Tecnologías y Versiones

Este sitio web es estático y está construido utilizando tecnologías web estándar sin frameworks pesados, asegurando máxima velocidad y compatibilidad.

- **HTML5**: Estructura semántica de todas las páginas.
- **CSS3**: Estilos personalizados (`css/style.css`). Uso avanzado de variables CSS, Flexbox, Grid y animaciones suaves.
- **JavaScript (Vanilla ES6)**: Interactividad, menús móviles, sliders de logos, y animaciones al hacer scroll (`js/main.js`). No depende de jQuery ni librerías externas para la lógica.
- **FontAwesome**: Iconografía vectorial utilizada en botones, secciones de servicios y footer.
